## About me

I am a Software Development and Programming student at **Elsewedy International Applied Technology School**, focused on building desktop applications with Python and C++.

I enjoy turning complex workflows into dependable tools with thoughtful interfaces, maintainable architecture, and practical automation. I also share technical content and development experiments on YouTube.

## What I build

- Python and C++ desktop applications
- Tkinter and Qt user interfaces
- Data processing and invoice reconciliation tools
- Serial communication, Arduino integration, and connected systems
- Modular object-oriented software
- User-focused UI/UX and structured software testing

## Featured project

### Invoice Reconciliation

A bilingual desktop application that compares Egyptian Tax Authority records with a company ledger, identifies matches and differences, and produces a clear report for review.
