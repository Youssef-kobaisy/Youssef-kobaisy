## About me

I am a Software Development and Programming student at **Elsewedy International Applied Technology School**, focused on building desktop applications with Python and C++.

I turn complex workflows into dependable tools with thoughtful interfaces, maintainable architecture, and practical automation. I also share technical content and development experiments on YouTube.

## What I build

- Python and C++ desktop applications
- Tkinter and Qt user interfaces

- Serial communication, Arduino integration, and connected systems
- Modular object-oriented software
- User-focused UI/UX and structured software testing
